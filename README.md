# 看不見的訪客 — 微塑膠偵探社 🕵️

高中彈性學習課程（2 × 50 分鐘）：**微塑膠 × 食品安全 × 科學素養**。
以 Feng & Chen (2026) 發表於 *Food Research International* 的微塑膠共污染綜述論文為素材，
讓學生扮演「微塑膠偵探社的一日探員」——先討論、再揭曉，用計算機估攝入量、玩排行榜猜吸附力，最後即時測驗。

🔗 **線上使用**：<https://tai-shengyeh.github.io/microplastic-teaching/>

## 課程內容

| 單元 | 內容 | 互動形式 |
|------|------|----------|
| 單元 1 | 這位訪客有多小？（定義、尺度、奈米塑膠與血腦屏障） | 討論 → 揭曉 |
| 單元 2 | 瓶裝水之謎（玻璃瓶 vs PET 瓶的反直覺結果） | 全班投票 → 揭曉長條圖 |
| 實驗室 A | 今天，你吃進幾顆？（一日微塑膠攝入計算機） | 滑桿 + 兩顆「地雷」開關 + 即時判定 |
| 單元 3 | 污染計程車（共污染：吸附 → 載運 → 釋放） | 討論 → 揭曉 |
| 實驗室 B | 吸附力排行榜（尼龍/PP/PVC/PE/PS 誰最會載客） | 點卡排序遊戲 + 對答案 |
| 單元 4 | 科學家怎麼看見看不見的東西（FTIR/拉曼指紋 + 方法學不統一） | 討論 → 揭曉 |
| 單元 5 | 從馬里亞納海溝到你的大腦（相關 vs 因果、預防原則） | 政策表決投票 → 揭曉 |
| 行動清單 | 六個本週減塑承諾 | 點選勾選（會記住） |
| 程式角落 | 用 Excel / Python / R 算年攝入量與不確定性區間 | 三選一動手算 |
| 結業測驗 | 10 題單選即時計分，可上傳成績給老師 | 測驗 + 雲端回收 |

計算機與排行榜的數字皆取自論文彙整之實測文獻（瓶裝水 Oßmann 2018、奈米塑膠 Qian 2024、微波釋放 Hussain 2023、手搖飲 Su 2025、重金屬吸附 Mo 2025、人腦累積 Nihart 2025）。

## 使用方式

直接用瀏覽器開啟 `slides.html`（或點上方線上連結）即可上課，無需安裝、手機／平板／桌機皆可。

- 🖥 **投影模式**：右上角按鈕一鍵放大字級並強制淺色，適合教室投影機；網址加 `?projector=1` 可直接開啟
- 🌓 自動跟隨系統深／淺色主題

### 給老師

- 「討論 → 揭曉」閘門：先讓學生分組討論或投票，按下按鈕才顯示科學家的答案
- 投票（瓶裝水之謎、政策表決）與測驗成績會上傳到 Firebase（離線或連線失敗時自動靜默停用，不影響其他功能）；成績只收班級座號與分數，不收姓名
- 攝入計算機為文獻平均值之教學估算，非精確暴露評估——「不同研究數字差很大」本身就是單元 4 的教學內容

## 檔案說明

- `index.html` — 入口頁（自動導向 slides.html）
- `slides.html` — 完整互動課程頁（單一檔案，含所有互動功能）

## 技術

純前端：HTML + CSS + 原生 JavaScript，單一檔案、無建置流程。雲端互動（投票統計、成績回收）使用 Firebase Firestore，以動態 `import` 載入、失敗時完全不影響頁面其他功能。
