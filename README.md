# 看不見的訪客 — 微塑膠 × 你的每一餐

食品安全科普教學投影片：以「微塑膠（microplastics）如何進入我們的食物與身體」為主題的互動式 HTML 簡報，適合課堂、科普講座與線上自學。

🔗 **線上觀看**：<https://tai-shengyeh.github.io/microplastic-teaching/>

## 內容

單一檔案的網頁版教學投影片，涵蓋微塑膠的來源、如何進入食物鏈與飲食、對健康的可能影響、檢測方法，以及日常可以怎麼減量。內含科普圖解與資料來源標註。

- `index.html` — 教學主頁（入口）
- `slides.html` — 投影片內容

## 使用

直接用瀏覽器打開 `index.html`（或點上方線上連結）即可播放，無需安裝、可離線。手機／平板／桌機皆可瀏覽。

- `←` / `→` / 空白鍵：切換頁面
- 桌機可點畫面兩側翻頁

## 技術

純前端：HTML + CSS + 原生 JavaScript，單一檔案、可離線、跨裝置。
